# CampusSplits – College Expense Splitter

CampusSplits is a simple web application designed to help friends manage shared expenses during trips and group activities.

## Problem

When friends go on trips together, it can be confusing to remember:

- Who paid for an expense
- How much each person needs to pay
- Which payments are still pending
- How much was spent in total

This can sometimes lead to confusion and unnecessary arguments between friends.

## Solution

I built **CampusSplits** to make group expense management easier.

The application allows users to create a group, add members, record expenses, and view the total and pending amounts in one place.

## Features

- Create an expense group
- Add and remove group members
- Add shared expenses
- Select who paid for an expense
- Automatically calculate expense splits
- View total expenses
- View number of expenses
- Track pending amounts
- Responsive design for mobile devices
